- **rsyslog** – Centralized log aggregation  
- **Custom Python Log Analyzer** – Multi-source correlation engine

## 🎯 What This Final Lab Simulates

This lab represents a **complete SOC operational workflow**, similar to what is implemented in real enterprise environments:

- Multi-source log aggregation (auth logs + IDS events)  
- Custom detection rule development (brute force, web attack, port scan)  
- Automated alert generation & severity classification  
- IP-based containment via `iptables` + Fail2ban  
- Playbook-driven incident handling  
- Structured reporting & execution tracking  

It is not a single script — it is a coordinated security ecosystem.

## 🔄 End-to-End Workflow Architecture

1. **Detection Layer**
   - Suricata rules identify suspicious traffic  
   - Authentication logs flag brute force attempts  

2. **Analysis Layer**
   - Python analyzer parses JSON + log files  
   - Alerts grouped by severity and source  

3. **Response Layer**
   - Response engine triggers automated containment  
   - Malicious IPs blocked via firewall  

4. **Playbook Layer**
   - Brute force & web attack response procedures  
   - Documented investigation, containment, recovery steps  

5. **Reporting Layer**
   - Structured JSON reports  
   - Alert archives  
   - Playbook execution logs
